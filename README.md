# v-local-chat · 本地聊天分析面板

> 面向 **macOS 微信**。把你自己的群聊和私聊，一键整理成**一眼能读的日报、干货精华、可导出的素材**。
> 全程在你自己的电脑上跑，**不上传、不联网、不接任何第三方 API**。

## 它解决什么

群里一天几百条消息，大佬的干货、别人发的链接、有用的素材，全刷过去了，回头根本翻不到。
私聊想留个上下文、想复盘一段关系，也没趁手的工具。

**v-local-chat 只做一件事并把它做好：把原始聊天记录，重组成人和大模型都好读的形态。**
它不替你做 AI 分析——它把消息整理成干净、带"谁回应谁"关系锚点的结构化文本，
你再丢给 Claude / Codex / 任意大模型去总结，事半功倍。

**两类人最用得上：**
- **想省事的你**：每天自动看群聊日报、把大佬干货一键沉淀。
- **做私域 / 微商运营**：上游群的方法论、素材、爆款内容，快速汇总整理成可复用的东西——这块整理需求，比你想的更高频。

## 三个场景

| Tab | 你给它 | 它给你 |
|-----|--------|--------|
| **群聊精华** | 群 + 时间范围 | 按发言人聚合、按贡献度排序，一眼看出谁在输出干货；干货 + 链接列表 |
| **素材提取** | 群 / 联系人 + 时间范围 | 图文 / 链接 / 文件 / 视频按时间分组，可导出 |
| **信息导出** | 联系人 | 完整对话时间线 + 上下文备份，导出 Markdown |

## 为什么它做得比同类好

同类工具你可能见过，但它们大多**只支持老版本微信**——新版一升级就失效。
原因是老方法依赖内存 dump 等手段，微信 4.x 加了密钥保护后就不灵了。
本项目走另一条路（hook 系统级密钥派生函数），**在当前最新版 macOS 微信 `4.1.11.55` 上实测可用**。
（关于"为什么别家在新版失效"，可参考这篇：https://x.com/leaf_sanren/status/2073069608437764266 ）

> ⚠️ 有时效性：微信每次大版本更新都可能需要重新准备、甚至方法失效。**当前版本我们是 OK 的，但不保证以后。** 这我们完全接受——能用一天是一天，方便自己和朋友而已。

真正的原创价值在 **"重组"这一层**（这层才是本项目）：

- **说话人绝不认错**：每条消息发言人来自数据库事实，不靠大模型猜；连没加好友、没备注的群成员，也能靠"引用配对"反解出真名。
- **"谁回应谁"变成确定信息**：引用回复（回了谁的哪句原话）、@提及（@了谁）都结构化提取——**这正是大模型最容易张冠李戴的地方**，我们把它从"猜"变成"事实"。
- **表情看得懂**：`[破涕为笑]` → 😂（白名单，绝不误伤营销文案、prompt 模板里的方括号）。
- **图片颜色是对的**：修了微信图片解密的一个色差坑（否则 JPEG 大面积偏色）；能解码的图颜色正常、可展示可导出。
- **人和 AI 都好读**：面板把回复渲染成低调引用行给你看；给大模型的素材另带文本锚点——两边诉求各取所需。

## 安装与使用

面板读取的是**已经解密到本地**的聊天库。

```bash
pip install flask pycryptodome zstandard
python3 panel/server.py          # 浏览器打开 http://127.0.0.1:5678
```

密钥获取与解密是一次性的环境准备，方法见
[`docs/key-extraction-technique.md`](docs/key-extraction-technique.md)。
本仓库**不附带**开箱即用的抓取脚本；请在**你本人授权的数据**上按文档自行准备。
（这一步怎么做对人最友好、零封号风险，见下方 QA 与技术文档。）

## 常见问题（QA）

**会不会封号？** —— **不会。** 核心操作都在 macOS 本机生态里完成，微信服务端监听不到这些动作。真正要避免的只有：别去自动化点微信界面、别高频操作，那才可能触发风控。正常准备一次密钥、之后纯本地只读，是安全的。

**会不会影响我的微信、导致登录 / 截图异常？** —— **不会。** 准备密钥时是对**复制到桌面的微信副本**操作，不动 Applications 里的原版微信，所以你怎么弄都不影响日常用的那个。

**Windows 能用吗？** —— 从技术逻辑判断，不一定行。**macOS 一定可以**，4.1.9 及以上都验证过（当前最新 4.1.11.55）。

**图片一定能拿到高清吗？** —— 看你在微信里点开看过没：点开过 → 有高清（有时凌晨后台批次才补到电脑）；只划过 → 本地可能只有缩略图。少数图是腾讯私有编码，本地无法解码。这些都是微信机制，不是工具的问题。
