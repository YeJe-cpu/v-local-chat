## 它解决什么

群里一天几百条消息，大佬的干货、别人发的链接、有用的素材，全刷过去了，回头根本翻不到。

它只做一件事并做到位：把原始聊天记录，重组成**人和大模型都好读**的形态。

它不替你做 AI 分析——而是整理成干净、带"谁回应谁"关系锚点的结构化文本，你再丢给 Claude / Codex / 任意大模型去总结，事半功倍。

> 想每天自动看群聊日报、一键沉淀大佬干货的你；做**私域 / 微商运营**、要快速汇总上游群方法论与爆款素材的人 —— 最用得上。

<br>

## 凭什么比同类靠谱

同类工具大多只吃老版本，聊天软件一升级就集体失效。本项目走的是另一条更稳的路，在**当前最新版**上实测跑通。为什么别家在新版全线阵亡，作者写过一篇复盘：[《我把某聊天软件的加密系统拆了》](https://x.com/leaf_sanren/status/2073069608437764266)。

但"能解密"只是入场券。真正的价值在**拿到数据之后怎么用**，这一层才是原创：

- **谁说了什么，绝不认错。** 发言人来自数据库事实，不靠猜。哪怕是没加好友、没备注的群成员，也能反解出真名——别人只能显示一串乱码 id。

- **"谁在回应谁"，从猜变成事实。** 引用回复、@ 全部结构化提取。这恰恰是大模型分析群聊最容易张冠李戴的地方，我们把它钉成确定信息——A 夸 B 不会被读成 A 夸 C。

- **表情不再是乱码。** `[破涕为笑]` 自动还原成 😂，且绝不误伤营销文案、prompt 模板里的方括号。

- **图片颜色是对的。** 啃下了图片解密里一个隐蔽的色差坑，能解码的图颜色正常、可展示可导出。

- **人看的和喂 AI 的，分开伺候。** 界面把回复渲染成低调引用行给你看；给大模型的素材另带纯文本锚点。

这些都不是纸上谈兵——图片高清的下载机制我们**跨设备、跨夜实测**才摸清；微信的私有图片编码我们**扫了全库 8 万张统计出真实占比与出现时间**；连"新群的入群通知会不会污染发言排行"这种边角都逐个填过。**每一条背后都是踩坑实证，合集见 [`docs/03-分析防踩坑.md`](docs/03-分析防踩坑.md)** —— 那也是为什么它比"能跑就行"的同类更让人放心。

## 三步跑起来

> **最省心：把这个仓库丢给你的命令行 Agent**（Claude Code / Codex / Grok build…），让它照着 [`docs/`](docs/) 帮你跑通。全程你只在两个点上亲手配合：**输一次本机密码、扫码登录**。其余复制、抓密钥、解密、起面板，Agent 都能代劳。

```bash
# 1) 获取密钥（一次性，指引见 docs/01-获取密钥-指引.md，本仓库不含抓取脚本）

# 2) 用密钥把聊天库解密成明文
python3 engine/decrypt_db.py --db-dir "<容器>/db_storage" \
    --keys ~/.config/wechat-keys.json \
    --out  "~/Library/Application Support/wechat-local-vault/decrypted/current"

# 3) 起面板（或双击 启动.command，会自动停掉旧实例再启动）
pip3 install flask pycryptodome zstandard
python3 panel/server.py            # 打开 http://127.0.0.1:5678
```

也可当 Claude Code Skill 用（见 `SKILL.md`），让 AI 直接调 `engine/vault.py` 读取分析。

## 常见问题

**会不会封号？**

不会。核心操作都在你 Mac 本机完成，服务端监听不到。真正要避免的只有：别去自动化点软件界面、别高频操作。正常准备一次密钥、之后纯本地只读，安全。

**会不会影响我的账号、导致登录 / 截图异常？**

不会。准备密钥时是对**复制到桌面的副本**操作，不动 `Applications` 里的原版，你怎么折腾都不影响日常在用的那个。

**Windows 能用吗？**

从技术逻辑判断不一定行。macOS 一定可以，4.1.9 及以上都验证过（含最新 `4.1.12`，实测通过）。

**图片一定能拿到高清吗？**

不一定，但工具会告诉你**具体卡在哪一步**：是**本地没下高清**（在软件里点开看一下、稍等再跑就能补上），还是**高清已经下了、却是腾讯私有编码解不开**（这种点开也没用，占比随新版在涨）。

反过来推是不成立的：**只有缩略图 ≠ 你没点开过**。工具用 `thumb_hd_is_wxgf` / `thumb_hd_missing` 两个计数分清楚，不用你猜，也不会给你无效建议。

**朋友圈图片能导吗？**

文案能精确到人到条；图片能解密，但所有好友的圈图混放一个缓存池、命名私有，无法自动归属到具体某人某条。这是已知的墙。

## 边界与免责

仅 macOS，抓密钥需要 frida；有时效性，软件大版本更新、或它把新消息轮转进新数据库时，需按同样流程再抓一次密钥（很快，详见 [获取密钥指引](docs/01-获取密钥-指引.md) 末尾"关于新数据库"）；部分图片私有编码本地无解。

**只在你本人拥有、且有权访问的数据上使用**，遵守当地法律与平台条款，作者不对任何滥用负责。
